HS STRIDE MODEL IMPORTER CORE - LLM API REFERENCE
===================================================
Version: 1.3.1 | .NET 8.0 | Package: HS.Stride.Model.Importer.Core
Copyright (c) 2025 Happenstance Games LLC | MIT License

Split multi-mesh 3D models (FBX, GLB, GLTF, OBJ, DAE) into individual mesh files
and generate Stride prefabs with proper hierarchy and transform preservation.

================================================================================
QUICK START
================================================================================

```csharp
using HS.Stride.Model.Importer.Core.Core;

using var importer = new StrideModelImporter();

var result = await importer.ImportModelAsync(
    fbxFilePath: @"C:\Models\Complex_Model.fbx",
    outputDirectory: @"C:\Output",
    strideProjectPath: @"C:\MyStrideGame",
    prefabName: "MyModel");

if (result.Success)
{
    Console.WriteLine($"Generated {result.GeneratedFiles.Count} files");
    Console.WriteLine($"Meshes split: {result.SplitResult?.MeshInfos.Count}");
}
else
{
    foreach (var error in result.Errors)
        Console.WriteLine($"Error: {error}");
}
```

================================================================================
STRIDEMODELIMPORTER (Main Entry Point)
================================================================================
Namespace: HS.Stride.Model.Importer.Core.Core
Implements: IDisposable

Constructor:
  new StrideModelImporter()    // No parameters

Methods:

  Task<ModelImportResult> ImportModelAsync(
      string fbxFilePath,               // Path to 3D model file
      string outputDirectory,           // Temp output directory for split files
      string strideProjectPath,         // Path to Stride project root
      string? prefabName = null,        // Custom prefab name (defaults to filename)
      IProgress<string>? progress = null) // Optional progress reporting

  ValidationResult ValidateInput(
      string modelFilePath,
      string outputDirectory,
      string strideProjectPath)

Notes:
  - Requires multi-mesh models (2+ meshes). Single-mesh models return a warning.
  - Temporary split files are cleaned up automatically after import.
  - FBX positions are auto-converted from centimeters to meters.
  - GLB/GLTF positions are used as-is (already in meters).

SUPPORTED FILE FORMATS
================================================================================

| Format | Extensions       | Export Format | Notes                          |
|--------|-----------------|---------------|--------------------------------|
| FBX    | .fbx            | .fbx          | Positions divided by 100       |
| glTF   | .gltf           | .gltf         | Positions used as-is           |
| GLB    | .glb            | .glb          | Positions used as-is           |
| OBJ    | .obj            | .fbx          | Exported as FBX                |
| DAE    | .dae            | .fbx          | Exported as FBX                |

FBXPROCESSOR (Mesh Splitting Engine)
================================================================================
Namespace: HS.Stride.Model.Importer.Core.Core
Implements: IDisposable
Dependency: AssimpNet 5.0.0-beta1

Methods:

  Task<FbxSplitResult> ProcessFbxFileAsync(
      string fbxFilePath,
      string outputDirectory,
      IProgress<string>? progress = null)

Notes:
  - Loads models with no post-processing to preserve exact data
  - Walks full scene hierarchy to extract all mesh nodes
  - Exports each mesh node as a separate file in source format
  - Zeroes out position in exported files (position stored in prefab)

COMMON PATTERNS
================================================================================

### Import with Progress Reporting
```csharp
using var importer = new StrideModelImporter();

var progress = new Progress<string>(msg => Console.WriteLine(msg));
var result = await importer.ImportModelAsync(
    @"C:\Models\Building.glb",
    @"C:\Temp\Output",
    @"C:\MyStrideGame",
    progress: progress);
```

### Validate Before Import
```csharp
var validation = importer.ValidateInput(modelPath, outputDir, projectPath);
if (!validation.IsValid)
{
    foreach (var error in validation.Errors)
        Console.WriteLine($"Error: {error}");
    return;
}
```

### Inspect Split Results
```csharp
var result = await importer.ImportModelAsync(...);
if (result.SplitResult != null)
{
    foreach (var mesh in result.SplitResult.MeshInfos)
    {
        Console.WriteLine($"{mesh.Name}: {mesh.VertexCount} verts, {mesh.FaceCount} faces");
        Console.WriteLine($"  Position: {mesh.Position}");
        Console.WriteLine($"  Materials: {string.Join(", ", mesh.MaterialNames)}");
    }
}
```
